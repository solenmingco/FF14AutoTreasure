# FF14 自动挖宝助手 (AutoTreasure)

面向 **国服（卫月 / XIVLauncherCN）** 的 FFXIV 挖宝流程自动化插件。

本仓库实现了需求思维导图中的 **阶段 1 / 2 / 6 / 7**，以及**自动前往主城市场布告板**；
阶段 4（战斗）、5（副本）**尚未实现**，界面上会明确标注，不会假装完成。

---

## 当前实现范围

| 阶段 | 内容 | 状态 |
|---|---|---|
| 1 买图 | **藏宝图等级下拉选择**（G1–G18 / S1–S5，从游戏数据读取）、金币余额检查、地图库存统计 | ✅ |
| 2 读图 | 背包 / 陆行鸟背包分仓队列统计 | ✅ |
| 3 寻路挖宝 | **自动前往任意主城市场布告板**（vnavmesh + Lifestream）；藏宝点坐标已读取 | ✅ 部分 |
| 4 开箱战斗 | 开箱、战斗循环、拾取 | ❌ 未实现 |
| 5 结果分支 | 进副本 / 下一张 | ❌ 未实现 |
| 6 丢弃垃圾 | **按物品名搜索勾选**、黑白名单、售价 / 品质判定、背包满触发、单次上限 | ✅ |
| 7 总控 | 循环开关、紧急暂停热键、日志、收益统计、拟人化间隔 | ✅ |

> **重要**：阶段 6 的「真正删除物品」通过 FFXIVClientStructs 调用游戏自身的
> `InventoryManager.DiscardItem` 实现。这是唯一一处越过 Dalamud 公开 API 的地方，
> 属于内存调用，游戏版本更新后可能失效。

### 三个下拉框

1. **藏宝图等级下拉**：读取游戏自己的 `TreasureHuntRank` 表，自动跳过空占位行，
   并从物品名里解析等级编号（G1…G17、S1…S4）。
   - **不使用手写物品 ID 列表**，国服 / 国际服都能正确显示。
   - 国服目前最高是 **G17**（缺 G18 与 S5），下拉框只显示实际存在的等级。
2. **主城下拉**：选定目标主城后 —
   - 当前地图已有市场布告板 → 直接经 vnavmesh 走过去；
   - 不在该地图 → 先用 **Lifestream** 传送，到达后自动走向布告板。
   - 布告板位置在**运行时从游戏对象识别**，不使用写死坐标。
3. **丢弃物品选择**：按名称搜索全游戏物品并勾选。

### ⚠️ 关于「按地图等级掉落物」的说明

需求里希望「按对应地图的凋落物下拉选择」。经逐项核实，
**游戏数据中不存在「某等级宝箱掉落哪些物品」的现成表**：

- `Treasure` 表只有宝箱名字（「寶箱」）和模型路径，**没有物品列表**；
- 全部行 `GatheringItem` 中**没有任何一张藏宝图**，挖宝不属于采集系统；
- 公开第三方掉落数据**明显不完整**（G17 仅 2 项、G18 仅 1 项、S1–S5 全为 0）。

因此本插件**没有硬写一份掉落表**（那等于编数据），改为
**可搜索的物品勾选器**：输入物品名 → 勾选 → 加入丢弃黑名单。
数据始终正确，国服可用中文名搜索。
选择地图等级时，界面会额外显示该等级的**真实藏宝点数量与分布地图**（这部分数据可靠）。

| 插件 | 用途 | 必需性 |

## 安装

### 方式一：从 Release 安装（推荐）

1. 打开游戏，输入 `/xlsettings`。
2. 切到「测试版」页签，在 **自定义插件仓库** 里填入：
   ```
   https://raw.githubusercontent.com/solenmingco/FF14AutoTreasure/main/pluginmaster.json
   ```
3. 输入 `/xlplugins`，在「全部插件」里搜索 **自动挖宝** 并安装。

### 方式二：本地开发安装

把编译产物目录加入 Dalamud 的开发插件目录，或直接在游戏内 `/xldev` 中指定。

## 使用

游戏内命令：

| 命令 | 作用 |
|---|---|
| `/at` 或 `/autotreasure` | 打开主窗口 |
| `/at on` | 开始自动循环 |
| `/at off` | 停止循环 |
| `/at panic` | 紧急停止 |
| `/at mb` | 前往所选主城的市场布告板 |
| `/at clearmb` | 取消前往市场布告板 |
| `/at reload` | 刷新游戏数据缓存 |
| `/at clear` | 清空日志 |

**紧急暂停热键**默认 `F12`，可在设置中修改虚拟键码。

首次使用建议按顺序：
1. 在「设置 → 地图 / 买图」的下拉框里 **勾选你要处理的藏宝图等级**（G1…G17 / S1…S4）。
2. 在「设置 → 市场布告板」的下拉框选择目标主城。
3. 在「设置 → 丢弃垃圾」里搜索物品名并勾选要丢弃的东西，配置判定规则。
4. 回到主窗口点「前往市场布告板」或「开始循环」，观察日志确认行为符合预期。

## 构建

需要 **.NET SDK 10.0.101**（Dalamud API 15 要求 `net10.0-windows`）。

```bash
cd AutoTreasure
dotnet build -c Release
```

`Dalamud.NET.Sdk` 需要能找到一个 Dalamud 安装来引用其程序集，按以下顺序解析：

1. 环境变量 `DALAMUD_HOME`
2. 默认路径 `%APPDATA%\XIVLauncher\addon\Hooks\dev\`（国服为 XIVLauncherCN 时路径可能不同）

若本机没装卫月，可手动下载 Dalamud 开发包并设置 `DALAMUD_HOME`：

```powershell
$env:DALAMUD_HOME = "C:\path\to\dalamud-dev"
dotnet build -c Release
```

产物位于 `AutoTreasure/bin/Release/AutoTreasure/latest.zip`。

## 发布新版本（游戏内自动更新）

1. 修改 `AutoTreasure/AutoTreasure.csproj` 里的 `<Version>`。
2. 打 tag 并推送：
   ```bash
   git tag v0.2.0.0
   git push origin v0.2.0.0
   ```
3. GitHub Actions 会自动构建并把 `latest.zip` 附到 Release。
4. 更新仓库根目录的 `pluginmaster.json` 中的 `AssemblyVersion`、`LastUpdate`
   与下载链接（链接指向 `releases/latest/download/latest.zip`，通常无需改动）。
5. 玩家在 `/xlplugins` 中点更新即可。
